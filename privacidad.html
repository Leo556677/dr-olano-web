Privacidad

Esta página explica, de forma práctica, qué datos utiliza la web de Dr. Olano durante una solicitud de cita.

Datos utilizados en la solicitud

El flujo puede solicitar nombre, número de celular, servicio elegido, fecha y hora solicitadas. Estos datos se utilizan para preparar la solicitud de cita y permitir que el usuario la envíe al centro por WhatsApp.

Borrador de cita

Si el usuario deja el proceso inconcluso, la página puede guardar un borrador en el almacenamiento local del navegador para poder retomarlo. La versión actual elimina automáticamente los borradores vencidos, los asociados a fechas pasadas o los que superan 24 horas.

WhatsApp

Los datos de la solicitud se transfieren a WhatsApp únicamente cuando el usuario decide continuar con el envío. Desde ese momento también resultan aplicables las condiciones y políticas de WhatsApp.

Medición de la landing

La página está preparada para medir eventos de conversión. Mientras no se configuren identificadores reales de Google Analytics o Meta Pixel, no carga esos rastreadores externos. Si se activan posteriormente, la implementación preparada evita enviar a esos rastreadores el nombre, teléfono, servicio concreto, diagnóstico, condición médica u otros datos médicos de la solicitud.

Finalidad

Los datos se utilizan para gestionar la solicitud, responder al usuario y coordinar la atención correspondiente. La solicitud enviada desde la web no constituye por sí sola una cita confirmada.

Consultas sobre tus datos

Para consultas relacionadas con una solicitud o con los datos enviados al centro, puedes comunicarte con Dr. Olano por WhatsApp.
